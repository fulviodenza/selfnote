Design documents

  • Brand assets: the logo in SVG and PNG.

Built on

  • Yjs and yrs: the CRDT engine, in JS and Rust, wire-compatible.
  • BlockNote: the block editor shared by every client.
  • axum: the Rust web framework behind the API.
  • Tauri 2: the desktop shell.
  • Expo: the mobile toolchain.
  • CloudNativePG: Postgres with continuous backup and point-in-time recovery.
  • MinIO: S3-compatible storage for files and backups.
