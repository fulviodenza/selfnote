Documentation

What Selfnote is, how the pieces fit, and how to have it running on your laptop in about three commands.

What you're running

Selfnote is a small system with a clear split:

  • API server (Rust, axum) — the control plane: accounts, workspaces, the page tree, permissions, room-token issuance, and the optional AI endpoints. Listens on :4445.
  • Sync server (Rust, yrs) — a WebSocket hub speaking the Yjs sync protocol. It relays edits between connected clients, tracks presence, and persists the update stream to Postgres. Listens on :4444.
  • Postgres — metadata, the append-only document update log, and compacted snapshots.
  • Clients — web (React + Vite), desktop (Tauri, bundling the web app), and mobile (Expo). All share @selfnote/core for sync and persistence, and the same BlockNote editor.

One origin serves the whole app: an nginx in front serves the static web client and proxies /api and /ws to the two services.

Quick start on your laptop

Prerequisites: Rust (stable), Node 22+ with pnpm 11+ (corepack enable), and Docker for the dev Postgres and MinIO.

  1. Clone and install: 
    git clone https://github.com/fulviodenza/selfnote && cd selfnote
pnpm install
docker compose -f docker-compose.dev.yml up -d
  2. Start the API server (runs migrations on boot) and the sync server, each in its own terminal: 
    cargo run -p selfnote-api

DATABASE_URL=postgres://selfnote:selfnote@localhost:5432/selfnote \
  ROOM_SECRET=dev-room-secret SYNC_REQUIRE_AUTH=1 \
  cargo run -p selfnote-sync
  3. Start the web client and open http://localhost:5173: 
    pnpm --filter @selfnote/web dev

Register an account and start editing. To see the point of the whole thing: open the same note in a second browser and type in both — then use Simulate offline in one, keep typing, and reconnect to watch the edits merge.

cargo clippy -- -D warnings
pnpm -r typecheck
pnpm smoketest             # end-to-end: live propagation + offline-merge convergence
