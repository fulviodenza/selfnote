Architecture Feature briefs

Self-hosting

Everything talks to two services and a Postgres. Put those three things somewhere you trust and every client follows.

The shape of a deployment

The browser and native clients all talk to api (port 4445) and sync (port 4444) plus Postgres. The web client is static files served by an nginx that also proxies /api and /ws to the two services, so one origin serves the whole app, and the client resolves its server from the page origin, so the same build works on any domain with nothing baked in.

Helm (recommended)

The chart at deploy/helm/selfnote deploys the api, sync, and web workloads, a WebSocket-aware Ingress, in-cluster MinIO for files and backups, and a CloudNativePG Postgres cluster with WAL archiving.

helm install selfnote deploy/helm/selfnote \
  --namespace selfnote --create-namespace \
  --values my-values.yaml

In your values, set at minimum:

  • your image registry and tags,
  • the ingress host (e.g. notes.example.com),
  • real secrets: jwtSecret, roomSecret, and the MinIO credentials. Change every change-me-* placeholder before exposing the instance.

The chart also has a first-class ai: block (see Enabling AI Assist), so AI provider credentials are wired without any manual kubectl set env.

The operator

For one-command installs and gated upgrades, the Go operator under operator/ provides a Selfnote CRD (kubectl get sn) whose reconciler owns the workloads and composes a Postgres cluster. It's the later-phase path; the Helm chart is the pragmatic first deploy while the operator matures.

A single box, without Kubernetes

Nothing requires Kubernetes: run Postgres, selfnote-api, and selfnote-sync as processes or containers, and serve apps/web/dist behind any reverse proxy that routes /api and /ws. apps/web/nginx.conf is the reference proxy config, and docker-compose.dev.yml shows the supporting services.

Backups you can trust

  • CloudNativePG does continuous WAL archiving plus daily base backups to MinIO, giving point-in-time recovery.
  • Yjs snapshots are also pushed to MinIO (versioned), so document content is independently recoverable.
  • deploy/restore-drill.sh verifies the whole path: backup, then restore into a fresh cluster. Run it; a backup you've never restored is a hope, not a backup.

Exposing it to the internet

Any ingress or tunnel works as long as WebSockets pass through. A Cloudflare Tunnel pointed at the web Service is a good zero-open-ports option for a homelab. Terminate TLS at your edge; room tokens and personal access tokens travel in headers.
