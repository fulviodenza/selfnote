Enabling AI Assist

AI is off by default and server-owned. Give the API one provider credential and the ✦ Assist panel appears on every client, with no client updates.

Pick a provider

ProviderYou needNotes
Claude CLI (subscription)a token from claude setup-token The selfnote-api image bundles the Claude Code CLI. Runs on your server, so document text never leaves your box. Uses your Claude plan; no per-request billing.
Anthropic APIANTHROPIC_API_KEY Pay-per-use against api.anthropic.com.
Ollamaa reachable OLLAMA_HOST Local open-weights models; fully self-hosted.

Detection order is CLAUDE_CODE_OAUTH_TOKEN → ANTHROPIC_API_KEY → OLLAMA_HOST. Set exactly one.

Claude CLI, step by step

  1. On any machine where you're signed into Claude, generate a long-lived token (valid about a year): 
    claude setup-token
  2. Store it as a secret, pasting at the silent prompt so it stays out of your shell history: 
    read -rs TOKEN && kubectl create secret generic selfnote-ai -n selfnote \
  --from-literal=CLAUDE_CODE_OAUTH_TOKEN="$TOKEN" && unset TOKEN
  3. Wire it to the API and restart: 
    kubectl set env deployment/selfnote-api -n selfnote --from=secret/selfnote-ai
kubectl rollout restart deployment/selfnote-api -n selfnote

Or let Helm wire it

The chart's ai: block replaces the kubectl steps. Reference a secret you created out-of-band, so the token never lives in your values file:

# values.yaml
ai:
  enabled: true
  provider: claude-cli        # claude-cli | anthropic | ollama
  existingSecret: selfnote-ai # keys: CLAUDE_CODE_OAUTH_TOKEN or ANTHROPIC_API_KEY

Ollama needs no secret, just a reachable host:

ai:
  enabled: true
  provider: ollama
  ollamaHost: http://ollama.ollama.svc:11434
  model: llama3

Verify

curl -H "authorization: Bearer <access-token>" https://<your-host>/api/ai/status
# → {"available":true,"provider":"claude-cli","model":"…","features":[…]}

Once available is true, the ✦ Assist button appears in the editor topbar on every client.

What you get in the editor

  • A streaming chat sidebar grounded in the current note; answers drop straight into the document.
  • Note-level actions: Summarize, Rewrite in my voice, Extract action items.
  • Staged AI edits: writes from AI arrive as proposals with a before/after diff, and become real edits only when a human accepts them.

Security notes

  • All /ai/* endpoints require auth, and completions verify workspace membership for the referenced document.
  • The CLI provider spawns a claude -p process per request with a 30s timeout; rate-limit it if untrusted users can reach your instance.
  • Prefer the local CLI or Ollama if document text must never leave your infrastructure.
