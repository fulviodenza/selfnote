Download

The clients are free and connect to any Selfnote server — yours, or one a friend hosts for you.

Android

Download selfnote-0.1.0.apk

Direct APK install (sideload): allow "install unknown apps" for your browser or file manager when Android asks. On first launch, enter your server address — the app verifies it and remembers it. All releases, including newer builds, are on the releases page.

iOS

No store build yet — run it from source with the Expo toolchain: cd apps/mobile && npm install && npm run ios (needs Xcode).

Desktop (macOS, Linux, Windows)

Built from source with Tauri 2 — native app and installer land under src-tauri/target/release/bundle:

cargo install tauri-cli --version "^2"
cd apps/desktop && cargo tauri build

Web

The web client ships with your server — whatever origin serves your instance is the app. Nothing to download.

The server

The part that makes it yours. Start with the self-hosting guide: a Helm chart for Kubernetes, or three processes and a Postgres on any box.
