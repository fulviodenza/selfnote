Selfnote support

Help with the Selfnote app for iPhone, iPad, Android, web and desktop: connecting to your server, signing in, sync and offline, AI, sharing, and how to reach us.

Get help

Everything goes to the issue tracker and is answered in public, so the next person with the same question finds the answer:

  • Something is broken, or you want a feature: open an issue. Say which client you are on (phone, web or desktop, and the OS version), which version of the server you connect to, and what you did just before the problem.
  • You cannot connect or sign in: read Connecting below first. Nine times out of ten it is the address.
  • A question about privacy: the privacy policy is short and specific.

Selfnote is open source. If you would rather read the code than file a report, the mobile app is at apps/mobile and the server at server.

Connecting

Do I need a server?

Yes. The app is a client for a Selfnote server, and it has no server of its own: the notes live on an instance you run, or one a friend, family member or colleague runs for you. The self-hosting guide covers a Helm chart for Kubernetes or three processes and a Postgres on any machine.

What do I type on the first screen?

The address of your instance. The host alone is fine, like notes.example.com; https is assumed and the API and sync paths are added for you. The app checks that a Selfnote server answers there before it saves the address.

It says "Couldn't reach that server"

  • The instance is on plain http. The app assumes https when you leave the scheme out, so type http:// explicitly for a server without a certificate, for example on a home network.
  • The address is a web page, not the server. Use the address you open the Selfnote web app at; the app derives the API and sync endpoints from it.
  • The server is not reachable from where you are. A home server behind a router needs a tunnel or a VPN to work from outside.
  • The server is down. Open the same address in a browser and see.

How do I switch to another server?

Settings has the server address. Change it and sign in again. Notes cached from the previous server stay on the device until you use Delete all data on this phone.

Your account

Sign in or create an account?

Accounts live on the instance, not with Selfnote. If this is your server and you have never used it, tap Create account. If someone else runs it, they either created an account for you or you create one with Create account and they add you to their workspace.

I forgot my password

There is no reset by email, because the server has no email service of its own. The person who runs the server can set a new password hash in the database. If that is you and you are stuck, open an issue and we will walk you through it.

Where is my password stored?

Nowhere on the device. Signing in trades it for two tokens that the app keeps instead. The server stores a hash. Details are on the privacy page.

Notes and sync

What do Live, Syncing and Offline mean?

The word next to the dot in the editor's top bar is the state of the connection to your server for the note you have open. Live means edits travel both ways instantly. Syncing means the connection is being made. Offline means there is none right now; keep typing, the note is saved on the device and merges when the connection comes back.

Will I lose edits made offline?

No. Every note is a CRDT, which means two people, or two of your devices, can edit the same page while disconnected and both sets of changes survive the merge. There is no "which version do you want to keep" dialog and no conflict copy.

Can I open several notes at once?

Yes. Notes open as tabs, shown in the switcher at the bottom of the editor. Tabs are remembered per device.

How do I recover an earlier version of a note?

Open the note, then its history. Versions are saved automatically and whenever you tap Save version. Restoring one writes it as a new edit, so nothing is ever destroyed and the people you share with see the restore like any other change.

Can I link notes to each other?

Yes. Type [[ in the editor to link another note. The backlinks panel shows which notes link to the one you are reading, and the graph view draws the whole workspace.

Tasks and calendar

How do I make a task?

Any note can be promoted to a task with a due date, status and priority from its menu, and any checklist item inside a note can be one too. The Tasks screen is the agenda across the workspace.

How do I see tasks in my calendar?

Settings has a calendar feed per workspace. Turning it on gives you a URL that Apple Calendar, Google Calendar or Outlook can subscribe to. Anyone with the URL can read your task titles and dates, so treat it like a password and revoke it from the same place if it leaks.

Sharing

How do I share a note with someone who has no account?

The Share action creates a public link. Anyone with it can read and edit that one note, with no account, until you revoke the link. The same screen shows how many times each link was opened and when, so you know when to kill it.

How do I work with others in the same workspace?

Ask the workspace owner to add your account. Roles are owner, admin, editor and viewer, and the server enforces them on every request. Members see each other's cursors while editing the same note.

AI

I do not see any AI features

That is expected on a plain server. AI is off until whoever runs the instance gives it one provider: a Claude subscription token, an Anthropic API key, or an Ollama host. The app then shows the Assist panel on every device. The AI guide walks through it.

Does AI change my notes without asking?

No. The in-app actions, Summarize, Rewrite in my voice and Extract action items, stream a result that you then insert or use to replace a selection yourself. Edits that come from outside the editor, from the Assist chat's "insert into note" or from Claude connected over MCP, arrive as proposals with a before and after diff, and nothing touches the note until you accept them.

What is MCP and why would I want it?

It lets Claude, in any conversation, file a summary into your notes, search them, and propose edits. See the MCP guide and the articles for what that looks like in practice.

Your data

Where are my notes?

On your server, in its Postgres database. The device keeps a cache of the notes you have opened so they load instantly and work offline. Your notes are sent nowhere else, and there is no analytics or tracking in any client. The full statement, including the one content delivery network the mobile editor loads its libraries from, is the privacy policy.

How do I get my notes out?

The database is yours, so a dump of it is a complete backup, and the import tool on the web client reads a whole Markdown or Obsidian vault in. Claude connected over MCP reads any note back as Markdown.

How do I remove the app's data from my phone?

Settings, then Delete all data on this phone. It signs you out and removes the cached notes, the server address and your preferences. Notes on the server are not affected. Deleting the app does the same.

Is the web or desktop client different?

Same features, same behaviour, same data. Anything you do on one client shows up on the others within a second when they are online. The clients page lists the few platform differences.
