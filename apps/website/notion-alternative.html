A self-hosted, open source Notion alternative

Pages, a block editor, real-time collaboration that works offline, tasks, links and AI on your own terms, on a server you run. Free, AGPL, with web, desktop and mobile apps.

Selfnote is a workspace in the shape people know from Notion: nested pages, a block editor with headings, todos, tables, code and callouts, real-time collaboration, tasks, and an AI assistant. The difference is where it runs. The server is yours, the apps are free, and the code is open source under the AGPL. There is no Selfnote cloud and no account with anyone but your own server.

What you get

  • The editor you expect. Pages inside pages, slash commands, tables, code blocks, callouts, math, images and files, with the same editor on web, desktop and mobile.
  • Real-time collaboration that works offline. Every page is a CRDT. Two people can type in the same sentence, one of them on a plane, and both sets of edits survive the merge with no conflict dialog. Notion is built around being online.
  • Links, backlinks and a graph. Type [[ to link a page, see what links back, and explore the workspace as a graph.
  • Tasks and a calendar feed. Any page or checklist item can carry a due date, status and priority, and the agenda publishes to Apple, Google or Outlook calendars.
  • Version history. Named restore points per page; restoring is a new edit, so nothing is ever destroyed.
  • AI you choose. Off by default. Turn it on with your Claude subscription running on your own server, the Anthropic API, or an Ollama model on your own hardware. Every AI edit is a proposal you accept or reject.
  • Claude can use it. An MCP server lets Claude search, read, file summaries into, and propose edits to your notes from any conversation.
  • Sharing with a kill switch. Public links per page, with view counts, and workspace roles for owner, admin, editor and viewer.

What Selfnote does not have

Honesty is cheaper than a disappointed install. Compared with Notion, Selfnote has no databases with board, calendar and gallery views, no template gallery, no marketplace of integrations, and no hosted free tier: someone has to run the server. The iPhone app is built from source until it reaches the App Store. If your workflow is a Notion database with twelve properties and three views, Selfnote is not that tool. If it is pages, writing, collaboration, tasks and AI that respects your data, it is.

Moving from Notion

Export your workspace from Notion as Markdown, unzip it, and import the folder as a vault from the Selfnote web client. Pages and their nesting come across, images come along, and callouts stay callouts. Two things to know: Notion appends an id to every exported file name, so titles arrive with that suffix until you rename them, and Notion databases export as CSV files, which are not imported. Links between pages arrive as text. The full steps are in moving from Notion to a self-hosted workspace.

Running it

A Selfnote server is three small processes and a Postgres: the API, the sync server and the web client. The self-hosting guide covers a Helm chart for Kubernetes, with backups and point in time recovery through CloudNativePG, and a plain install on any machine. A home server or a small VPS is plenty.

Frequently asked questions

Is Selfnote free?

Yes. The server and every client are free and open source. You pay for the machine you run it on, and for an AI provider only if you pick a paid one.

Is Selfnote open source?

Yes, under the AGPL-3.0. The whole monorepo, server and clients, is on GitHub.

Does it work offline?

Yes, on every client. Notes are cached on the device, you keep writing without a connection, and edits merge when you are back, including edits other people made in the meantime.

Can several people edit at once?

Yes. Pages are CRDTs, so collaboration is real time with visible cursors, and it survives one of the editors going offline.

Does it have AI?

Optional. The server operator enables one provider: a Claude command line tool running on the server itself, the Anthropic API, or Ollama. The clients then show an Assist panel, note actions and AI edit proposals. With the local options your notes never leave your machine.

Can I import from Notion or Obsidian?

Obsidian vaults import directly, folders, images and wiki-links included. Notion exports as Markdown and imports the same way, with the caveats above.

How does it compare with AppFlowy, AFFiNE, Docmost or Outline?

They are all good self-hosted options with different shapes. The short version: AppFlowy and AFFiNE are closest to Notion's databases and whiteboards, Docmost and Outline are team wikis, and Selfnote is pages plus real-time offline collaboration, tasks and a provider-agnostic AI with a review step. The long version is the best self-hosted Notion alternatives in 2026.

What does it run on?

Anything that runs Postgres and two small Rust binaries: a Kubernetes cluster through the Helm chart, a VPS, a home server, or a laptop for trying it out.
